# KyDog 的文献源

KyDog 用两个工具检索文献：

- **fastpaper**：随应用打包的命令行工具，通过各源的公开 API 检索、查询元数据、追溯引用关系、下载 PDF。
- **slowpaper**：智能体在应用内置浏览器中操作，访问没有 API 或 API 访问受限的源。操作过程显示在浏览器侧栏中。

两个工具没有主次之分。智能体先判断所需文献收录在哪些源中，再使用对应的工具，使用时无需指定。slowpaper 找到的论文如果有 DOI、arXiv id 或 PMID，后续的核验、引用关系、被引数与开放获取全文都转由 fastpaper 处理。

## fastpaper：通过 API 访问的源

目前支持 26 个源。表中「PDF」指 fastpaper 可以把全文下载到项目的 `papers/` 目录；「引用关系」指可以查询施引文献与参考文献；「被引数」指检索结果中包含被引次数。

榜单给的是社区关注度，不是引用影响力，两者不能互相替代。榜单里的每一篇都是 arXiv 论文，全文按 arXiv id 下载。

### 需要填写密钥的源

在「设置 → 文献检索密钥」中填写。未填写时，以下源会被限流或无法使用：

| 设置项 | 作用于 | 未填写时 |
|---|---|---|
| Semantic Scholar | Semantic Scholar | 被严重限流，基本不可用 |
| CORE | CORE | 匿名请求大多被限流拒绝 |
| Unpaywall 邮箱 | Unpaywall | **必填**，未填写时无法使用 |
| NCBI | PubMed、PMC | 每秒限 3 次请求，填写后为 10 次 |
| OpenAlex | OpenAlex | 免费额度为填写后的十分之一 |
| 联系邮箱 | Crossref、OpenAlex 等 | 无法进入 Crossref 的 polite pool |
| NASA ADS | NASA ADS | **必填**，未填写时无法使用 |

Hugging Face Papers 没有对应的设置项：它的 `HF_TOKEN` 同时是 Hugging Face 模型服务的密钥变量，在这一页填写会让同一个环境变量有两个来源，因此不开放。匿名调用为每 5 分钟 500 次请求，日常够用。

### 未收录的源

- **Google Scholar、百度学术**：两个平台收紧了 API 访问。KyDog v0.3.1 把 fastpaper 升级到 0.8.1 时，这两个源已从来源列表中移除，现由 slowpaper 通过内置浏览器访问。
- **中文期刊与学位论文**：fastpaper 不覆盖中文期刊。Europe PMC 里的中国生物医学文摘只有 2000–2007 年的约 14 万条、早已停更，按语种筛出来的中文刊也只是少数被 MEDLINE 收录的期刊的英文题录，两者都不算中文期刊检索。这部分由 slowpaper 处理。

## slowpaper：通过内置浏览器访问的源

slowpaper 的源分为三类：

- **学术搜索引擎**：用于发现文献，返回候选论文与链接，本身不提供全文。
- **开放获取全文源**：全文免费，但没有 API 或设有反爬措施，fastpaper 无法访问。
- **订阅全文源**：全文需要机构订阅。

前两类的每个源都有一份经过实测的操作卡片，规定了检索、翻页与提取结果的步骤。

### 学术搜索引擎

| 源 | 收录范围 | 可获取的内容 |
|---|---|---|
| Google Scholar | 国际期刊、预印本、国际会议、学位论文、专利与灰色文献；聚合同一篇论文的所有版本 | 结果列表、被引数、开放获取副本的 PDF 直链 |
| 百度学术 | 中文期刊、学位论文、国内会议 | 结果列表，以及同一篇论文在知网、万方、维普、国家科技图书文献中心、期刊官网等处的全文入口 |

智能体在任务开始时按目标文献确定检索源：中文期刊与学位论文使用百度学术，国际文献与跨库检索使用 Google Scholar；两类都需要时（例如系统综述），同时检索两个源，结果合并为一张表。

出现验证码时（百度学术的「百度安全验证」、Google Scholar 的 reCAPTCHA），智能体暂停检索，请用户在浏览器侧栏中完成验证后继续。Google Scholar 有时直接拒绝访问，页面上没有可操作的验证，这时智能体改用另一个源，不重复尝试。

| PeerJ | 生命科学与计算机科学开放获取期刊，开放评审 | 详情页有 PDF，可下载 |
| ChemRxiv | 化学预印本 | 详情页有 PDF，可下载 |
| SSRN | 金融、管理、法学的工作论文 | 详情页有 PDF，可下载 |
| AGRIS | 联合国粮农组织的全球农业文献库 | 只有书目记录，没有全文 |
| PubScholar | 中国科学院文献情报中心的公益学术平台，约 1.08 亿条，中文覆盖最广的免费入口 | 支持检索；全文入口尚未实测 |

PeerJ、ChemRxiv、SSRN、AGRIS 使用 Cloudflare 防护。内置浏览器通常可以正常访问，偶尔出现人机验证，需要用户点击完成。

### 订阅全文源

知网、万方与各出版社的订阅数据库目前没有操作卡片。

- **在校园网内或连接学校 VPN**：内置浏览器使用系统网络，可以打开学校已订阅的页面，智能体可以直接使用。
- **不在校园网**：用户可以先在内置浏览器中用学校账号登录，再由智能体继续操作。通过学校账号登录获得的访问权限，智能体只用来向用户报告链接，不下载文件，以免出版社针对自动化下载的封禁落在用户本人的校园账号上。
- **CARSI 自动登录**（用学校账号自动完成联邦认证）正在开发，本版本未开放，计划在后续版本提供。

### 其他网页

用户提供链接，或者智能体需要阅读论文的落地页时，可以在内置浏览器中打开并读取页面内容。在没有操作卡片的检索站点上，智能体的尝试次数有上限，达到上限后把链接交给用户。回复中会注明这次检索用的是没有操作卡片的站点；没有检索到，不等于该站点没有收录。

### 下载规则

- 有 arXiv id、PMC id 或 DOI 的论文，优先由 fastpaper 下载。
- 其他 PDF 直链使用浏览器标签的 cookie 下载，保存到项目的 `papers/` 目录。许多源的 PDF 在浏览器之外直接请求会被拒绝。
- 只保存 PDF 文件。下载到的内容不是 PDF（例如登录页或拦截页）时不保留文件，并报告未获取到全文。这与「该论文没有全文」是两种不同的情况。
- 每个回合（从用户发出一条消息到智能体回复结束）最多下载 10 个文件，单个文件不超过 50 MB，超出部分只报告链接。
- 网页自动触发的下载一律取消，只执行智能体明确指定了地址的下载。
