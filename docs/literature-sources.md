# KyDog 的文献源

KyDog 找论文用两套工具，各自接不同的源：

- **fastpaper**：随应用打包的命令行工具，走各个源的公开 API。一条命令拿回一段结构化结果，快，也省上下文。
- **slowpaper**：智能体在 KyDog 的**内置浏览器**里操作，去没有 API 的源（或者 API 已经收紧、只能用网页访问的源）。它慢，但能到 fastpaper 到不了的地方。你在浏览器侧栏里能看到它打开了什么页面、点了什么。

两边不分主次，也不分先后。智能体先判断这次要的文献在哪些源里，源定了，用哪个工具也就定了。在浏览器里找到的论文，只要有 DOI、arXiv id 或 PMID，核验、引用关系、被引数和开放获取全文都交回 fastpaper 去取。

你不需要自己指定用哪个工具。

### 要填密钥的源

在「设置 → 文献检索密钥」里填。不填也能用，但下面几个源会慢很多，或者干脆用不了：

| 设置项 | 作用于 | 不填会怎样 |
|---|---|---|
| Semantic Scholar | Semantic Scholar | 被重度限流，基本不可用 |
| CORE | CORE | 匿名请求基本都被限流拒绝 |
| Unpaywall 邮箱 | Unpaywall | **必填**，不填这个源用不了 |
| NCBI | PubMed、PMC | 限速每秒 3 次，填了是 10 次 |
| OpenAlex | OpenAlex | 免费额度小十倍 |
| 联系邮箱 | Crossref、OpenAlex 等 | 不能进 Crossref 的礼貌池 |

### 不在这里的

- **Google Scholar、百度学术**：两个平台收紧了 API 访问，KyDog v0.3.1 把 fastpaper 升到 0.8.1 时，它们已经从来源列表里移除。现在由 slowpaper 在内置浏览器里访问，见下文。
- **中文期刊与学位论文**：fastpaper 没有通用的中文源（中文生物医学文献可以走 Europe PMC 里的中国生物医学文摘），这部分也交给 slowpaper。

## slowpaper：内置浏览器里的源

slowpaper 的源分成三类：

- **学术搜索引擎**：只负责找，产出候选论文和链接，本身不放全文。
- **OA 全文源**：全文免费，但没有 API，或者有反爬，fastpaper 够不着。
- **订阅全文源**：全文要机构订阅才能看。

前两类已经有专门的操作卡片：智能体照着一段实测过的步骤操作，一两次往返就能拿到结果。

### 学术搜索引擎

| 源 | 适合找什么 | 能拿到什么 |
|---|---|---|
| Google Scholar | 国际期刊、预印本、国际会议、学位论文、专利与灰色文献；同一篇论文的「所有版本」聚合 | 结果列表、被引数、开放副本的 PDF 直链 |
| 百度学术 | 中文期刊、学位论文、国内会议 | 结果列表，以及同一篇论文在知网、万方、维普、国家科技图书文献中心、期刊官网等处的全文入口 |

智能体一开始就按目标文献定用哪个：中文期刊和学位论文走百度学术，国际文献、跨库查全走 Google Scholar，国内外都要（比如系统综述）就两个都查，结果合并成一张表。

**遇到验证码交给你。** 百度学术的「百度安全验证」、Google Scholar 的 reCAPTCHA 出现时，智能体会停下来请你在浏览器侧栏里点一下，你点完它接着往下走。Google Scholar 有时直接拒绝访问（页面上没有能点的东西），这时智能体会换源，不会反复重试。

### 订阅全文源

知网、万方、各家出版社的订阅库，目前还没有专门的操作卡片。

- **你在校园网里，或者开着学校 VPN**：内置浏览器走的是系统网络，学校订阅的页面照常能打开，智能体可以直接用。
- **不在校园网**：你可以自己在内置浏览器里用学校账号登录，再让智能体接着操作。用学校账号登录拿到的订阅权限，智能体只用来把链接报给你，**不会替你下载**。出版社对自动化下载的封禁会落在你本人的校园账号上。
- **CARSI 自动登录**（用学校账号自动完成联邦认证）已经在开发，这一版还没有开放，放在后续版本。

### 其他网页

你给一个链接，或者智能体要读某篇论文的落地页，它都可以在内置浏览器里打开并阅读。遇到没有操作卡片的检索站点，它只会做有限的几步尝试，到上限就把链接交给你。它会写明走的是这条没有卡片的路，不会把「没找到」说成「这里没有」。

### 下载的规矩

- 有 arXiv、PMC 或 DOI 标识符的论文，优先交给 fastpaper 下载。
- 其余的 PDF 直链，带着那个浏览器标签的 cookie 去下载，存进项目的 `papers/`。很多源的 PDF 离开浏览器直接请求会被拒绝。
- 只收 PDF：下载下来不是 PDF（比如是一张登录页或拦截页），就不留文件，并如实告诉你没取到。这和「这篇没有全文」是两回事。
- 一个回合（你发一条消息到它回完）最多下载 10 个文件，单个不超过 50 MB。超出的只把链接报给你。
- 网页自己弹出的下载一律取消。能下载的只有智能体明确点名的那个地址。
