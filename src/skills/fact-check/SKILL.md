# 事实核验

输入是**一条待判定的断言**，输出是**一个判定**。这是唯一一个有对错的 skill——别的产出可以见仁见智，这份不行。

**用用户说话的语言写。**

## 和其他 skill 的分工

| | 问题 |
|---|---|
| `/research-ideation` | 我这个选题站不站得住 |
| `/literature-review` | 这个领域是什么 |
| `/research-frontier` | 最近发生了什么 |
| `/paper-summary` | 这篇论文怎么写进我的论文 |
| **`/fact-check`** | **这句话成不成立** |

## 开工前

1. `date +%F`
2. `ls papers/` —— 相关论文可能已经有了。
3. **read fastpaper 的 SKILL.md**（在 `<available_skills>` 里）。

## 怎么跑检索命令

AGENTS.md 的「用工具的方式」全部适用。多条检索式用多个并行调用，但**下载和可能被限流的调用分 4–6 个一批**——一次并行十几个 `get` 会让 Crossref 返回 429。

只有一样东西该写进磁盘：最终那份报告（以及 `fastpaper download` 自己放进 `papers/` 的 PDF）。

下载失败**先看退出码**：`4` = 这个源就是没有，换个源才有意义；`2` = 命令写错了；`1` = 别的问题。

## 第 1 步：把断言变成可判定的形式

**这一步跳过，后面全是白做的。** "可穿戴设备能预警心梗"没法判定——什么人群？什么设备？提前多久？以什么算预警？不先钉死这些，找到的任何证据都既能说支持也能说反对。

做法：把原断言拆成 **2–5 条可独立判定的子命题**，每条都要满足「能想象出一个能证伪它的实验」。

拆完**用 `ask_user_question` 让用户确认**（必须单独调用）。同一句话往往有几种拆法，**只有用户知道他问的是哪个意思**——这是这个 skill 里 ask 唯一不可替代的地方。给 2–4 个拆法当选项，每个选项的 `description` 写清这么拆之后要去验什么。

用户在命令里已经把话说死了的，不用问。

### 给每条子命题定类型

**类型决定判定标准，不分类就判不准**：

| 类型 | 判定标准 |
|---|---|
| **存在性**「有人做过 X」 | 找到一篇即成立 |
| **普遍性**「X 总是导致 Y」 | **一个反例即推翻** |
| **因果**「X 导致 Y」 | 相关性不够，要干预性或准实验证据 |
| **定量**「准确率超过 90%」 | 必须连同条件一起判定：什么人群、什么数据、什么阈值 |
| **比较**「X 优于 Y」 | 要看比什么指标、在什么条件下比、差异有多大 |

## 第 2 步：找证据，正反都找

**只找支持证据是确认偏误，这是这类工作最常见的失败。** 正反两路必须都走。

### 正面证据，按研究设计分层

`pubmed` 和 `pmc` 的 `[pt]` 过滤实测有效（不存在的类型会报 `No results found`，互斥类型组合返回 0 条）：

```bash
fastpaper search pubmed "<子命题的词> AND meta-analysis[pt]" -n 8
fastpaper search pubmed "<子命题的词> AND systematic review[pt]" -n 8
fastpaper search pubmed "<子命题的词> AND randomized controlled trial[pt]" -n 8
```

**从强到弱依次找，找到强的就不必往下挖**：meta 分析 / 系统综述 → 随机对照试验 → 前瞻队列 → 回顾性研究 → 病例报告 → 专家意见。

非生医领域没有 `[pt]`，用其他信号判强度：多中心还是单中心、公开基准还是自建数据集、有没有独立复现、样本量、是不是预印本。

### 反证，专门去搜

支持证据会自己跳出来，反证不会——必须专门找：

```bash
# 否定词组 × 主题词
fastpaper search pubmed "<主题> AND (\"no significant\" OR \"failed to\" OR \"did not improve\" OR \"no association\")" -n 8
fastpaper search europepmc "<主题> AND (\"negative result\" OR \"could not replicate\")" -n 8

# 谁在后面反驳了它
fastpaper cite <关键支持文献的DOI> --direction incoming -n 20
```

`cite --direction incoming` 是找到"这篇当年的结论后来被推翻了"的主要途径。**一条断言如果只有旧证据支持、而新证据都在反对，判定必须反映这一点。**

### 写进 query 的过滤条件要复验

`[pt]` 由 pubmed 解析，不支持的会明确报错。但**别的写进 query 字符串的条件不一定**——`europepmc` 的 `CITED:>N` 就被静默忽略（要用区间形式 `CITED:[N TO *]` 才生效）。**任何写进 query 的过滤条件，用一个极端值再跑一次验证它真的生效**（阈值拉到极高应返回零条）。

## 第 3 步：查撤稿

**每一篇要当证据用的论文，都要过这一关。** 引用被撤稿论文做证据，是事实核查里最严重的失误。

```bash
fastpaper search pubmed "<该论文的题名关键词> AND retracted publication[pt]" -n 3
```

命中就是被撤了。实测：Wakefield 1998 那篇能查出来，未撤稿的论文返回 `No results found`。

**这个检查只在 `pubmed` / `pmc` 有效**，非生医领域的撤稿查不到——那时在报告里如实写明这一项没做，不要假装做过。

## 第 4 步：核对原文

进了报告的每一条具体数字、效应量、结论方向，都要回原文核到。

```bash
fastpaper read papers/<file>.pdf --list-sections
fastpaper read papers/<file>.pdf --grep "<关键短语>" --context 500 --max-matches 10
```

`--section --format json` 会返回 `heading` 的 `text` / `page`，用来标出处。

**核不到原文的证据不进报告。** 一条核不实的证据会让整个判定失效。

## 第 5 步：判定

**五档，每档的判准写死，不许含糊**：

| 判定 | 什么时候用 |
|---|---|
| **成立** | 有直接证据支持，且专门找过反证没找到 |
| **有条件成立** | 在特定人群 / 条件 / 口径下成立，超出即无证据或有反证。**这是学术断言最常见的真实状态**，不要为了给个痛快答案把它挤成"成立" |
| **证据不足** | 没找到足以判定的证据。**必须说清是哪一种**：没人做过 / 做过但没报告这个终点 / 可能是我没搜到（写明搜了哪些源和词） |
| **有反证** | 存在与断言相反的证据，但不足以完全推翻（只有一项研究、或条件不同） |
| **不成立** | 有力证据表明断言错误，或普遍性断言被反例推翻 |

**判定必须带边界。** 不是"成立/不成立"，而是"**在什么范围内成立、超出什么范围就没有证据**"。学术断言几乎从来不是无条件的，一个不带边界的判定基本一定是错的。

**"找不到证据"不等于"不成立"。** 这是事实核查最常犯的错。没找到可能是没人做过、可能是发表偏倚、可能是你没搜到——三种情况对用户的含义完全不同，必须分开写。

## 写报告

模板在 `assets/report-template.md`，用 `write` 写到**项目根目录**：

```
fact-check-<断言简称>-YYYY-MM-DD.md
```

和另外四个 skill 同一套样式。**控制在 800–1200 字**——核查报告的价值在判定和证据链，不在铺陈。
**模板里两种引用块，别搞混。** 以 `〔写作指导〕` 开头的那些是写给你看的，**整块（到空行为止）都不进报告**，一条都不许留；其余 `>` 引用块——开头那条判定行、以及「被核验的原话」那条——**是报告的一部分**，原样保留并把占位符填好。


**只用纯 Markdown，不写 HTML 标签**——KyDog 的渲染器没有 rehype-raw。

**文献首次出现时写「作者（年份）《完整题名》」**，题名不许用省略号截断。

写完在对话里给三句话：判定是哪一档、最关键的一条依据、报告路径。

## 诚实边界

- **每条证据都经过原文核验和撤稿反查**，做不到的如实写明没做。
- **搜不到 ≠ 不成立。** 写清在哪些源、用哪些词没找到。
- **一个 id 都不许编。** 每个 DOI / PMID 都必须回源确认过。
- **区分"文献说的"和"我的推断"。** 判定本身是推断，它依据的证据不是——两者要分得清清楚楚。
- 没有影响因子、没有期刊分区，**证据强度只按研究设计和样本判断**，不按期刊名气。
