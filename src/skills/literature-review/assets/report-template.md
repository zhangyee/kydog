# 第一部分：文献综述

> 〔写作指导〕**以下到分隔线为止可整段粘进论文。**
>
> 硬规矩：不出现 `[仅摘要]`、"本报告"、"我们检索了"、"见第 N 节"，不出现任何元信息。
> 连续散文，不是论文清单——如果每段都是「X 等做了 A，Y 等做了 B」，那是清单不是综述。

# 第二部分：综述报告详情

> 〔写作指导〕以下不进论文，是这份综述怎么来的、以及从中读出了什么。
>
> **文献首次在本部分出现时，写「作者（年份）《题名》」**；同一小节内再次提到才简写成
> 「作者（年份）」。第一部分有紧挨着的参考文献表可查，这一部分没有——只写作者年份，
> 读者对不上是哪篇，也想不起来前面有没有出现过。表格里已有题名列的不必重复。
> **题名必须完整照录，不许用省略号截断、不许自行缩短**——读者要拿它去检索。

## 一、这片领域现在是什么样

> 〔写作指导〕三到五段散文，给一个不熟悉这个方向的读者一张地图：它从哪来、现在分成哪几条路线、
> 争的是什么、最近在往哪走。这一节要能被单独读懂。

> 〔写作指导〕六节按顺序写。空的一节也保留，写明"未找到"并说明搜了什么关键词、哪些源。
