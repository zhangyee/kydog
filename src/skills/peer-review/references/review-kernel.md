# 评审内核

三步：**中性映射 → 整体判断 → 逐条检查**。这份规程被 `/peer-review`（自评）与 `/peer-review-response`（评别人）共用——两个 skill 的 `references/` 各有一份，**逐字节相同，由单测钉死**；改这份必须两边一起改，别在任何一边单独发挥。

## 第 1 步：中性映射

先不带立场把稿子测绘一遍：研究问题、对象/数据、设计、每一条核心主张（原文引语记下来）。只描述，不评判。

这一步是后面所有批评的锚点——批评一个自己脑补出来的版本，是评审最难堪的失败方式。主张清单尤其重要：第 3 步的每条意见都要能指回这里的某条主张或某个环节。

## 第 2 步：整体判断（先于一切逐条意见）

两个问题，按顺序：

1. **论证链断没断**：假设 → 设计 → 分析 → 结果 → 结论，一环一环追。设计测不了假设、结论超出结果，断在哪一环就指认哪一环。
2. **声称的贡献成不成立**：作者说的新意，用检索去核（table 格式），找最接近的前置工作。铺几条 query 你自己定，判据只有一条：**够指名最接近的前置工作、或确认没找到为止**——这是为判断贡献服务的定向检索，不是综述，铺开扫领域是 `/literature-review` 的活。「已有人做过」这四个字必须指向检索确认的具体论文，凭印象说等于没说。

   原创性在全局判断里要落成三句可核的话：**新意坐在哪一层**（概念 / 方法 / 工程 / 应用）；**与最接近前置工作的差量是什么**——差距陈述要能被一句话证伪（「他们只做到 X，本稿做到 Y」；「更深入」「更系统」这类对任何论文都成立的话不算）；**这个差量对目标场合够不够分量**——分量是相对期刊/会议的，目标场合不明就问用户，没有场合就没有判决。

整体有致命伤——链条断了、贡献已被别人做掉、结构需要推倒重来——**报告里直说「这稿子还没到逐条评审的阶段」**，把证据集中在全局问题上，不要再铺三十条小意见。一份指出根本问题的短评审，比一份掩盖根本问题的长清单对作者有用得多。

## 第 3 步：逐条检查

按 pass 过，每个 pass 一个问题：

- **方法与统计**：判据随稿件类型走，不套教条——不要机械说「n<30 太小」「必须 Bonferroni」，说得出后果才算意见。四分法分清：**未报告**（信息不够，转「未能评估」）≠ **设计疑点**（报告的方法可能答不了问题）≠ **自相矛盾**（稿内两处对不上，引语并列贴出）≠ **诚信疑点**（中性描述，建议用户走编辑保密渠道，不做指控）。
- **因果语言**：设计撑不起的因果词逐个抓——横断面数据写 "predicts / causes / 导致"，就是一条意见。
- **数字与解读对齐**：同一批结果能不能讲出相反的故事？机制主张有没有对应的测量？效应量只差一点却写「显著优于」——声称与证据的落差都算。
- **文献**：两件事都要回源。漏引 → 检索确认那篇真的存在且相关；引文抽查 → 挑**承重的**引文回源核验。挑几篇你自己定，判据只有一条：**这条引文塌了，会不会带塌某条意见或稿子的关键主张**。核验分两档，见下节。
- **图表**：工具读不了图。能靠图注和正文交叉判断的就判断，判断不了的**列入「未能评估」**，不硬评也不沉默。
- **写作**：最后、最轻。术语不一致、结构混乱才值得写，风格偏好不值得。

### 引文核验分两档

默认**摘要档**：`fastpaper get <id>`，核存在性、主题相关、结论方向——背景类、存在性引文到这一档就够。

两种情形**必须升级全文档**（`fastpaper download <id> -d papers/`，再 `fastpaper read --grep` 定段比对）：

1. 稿件把**具体数字、引语、子群结论、方法细节**挂在该引文上——这些东西摘要里没有，摘要档核了等于没核。
2. 你准备写**「该引文不支持此论断」**这类意见——这是指控级判断，等于说作者引用失实，必须全文核实；拿不到全文就把措辞降格（「从摘要看未见支持，未能取得全文核实」），不许按全文核实过的口气写。

下载失败先看退出码（`4` = 这个源就是没有，换个源才有意义），最终拿不到就退回摘要档并如实标注。**仅摘要核验的判断在「依据」里标 `[仅摘要]`**；报告的局限 / 边界一节要写清引文核验做到了哪一档。

## 严重度（判据写死，不许含糊）

| 级别 | 判据 |
|---|---|
| **Major** | 不解决则中心结论不成立，或方法/统计有实质缺陷。**必须能指名具体缺陷**：缺哪个对照、哪一步因果越权、漏了哪篇检索确认过的文献。「感觉不够深入」不是 Major。 |
| **Minor** | 局部问题，改了更好，不改不动摇中心结论。 |
| **未能评估** | 材料里没有的东西（图、数据、补充材料）。**标出来，不当缺陷记**——「未报告」和「有毛病」是两回事。 |

**反配额**：某一级没有意见就写「未发现」，不许为了显得全面凑数。**Major 超过 8 条**，说明病在更上游——回到第 2 步，把它们收拢成整体判断。

## 每条意见五要素

- **位置**：节名 + 原文引语（20 词以内）
- **问题**：一两句，说事实
- **为何重要**：对结论或读者意味着什么
- **建议**：具体到能执行——「补充 X 对照」「把 'causes' 改为 'is associated with'」，不是「建议加强」
- **依据**：方法学论点附文献完整出处（回源核验过的）；显而易见的问题可省

意见编号用**全局顺序号**：Major 从 1 起，Minor 接续（Major 是 1–5，Minor 就从 6 起）。严重度由分节标题和每条的标注承载，**不编进编号**——这是学界惯例（编号管定位，严重度靠分节），引用某条时写「意见 N」。

**评审自身引用的文献，报告末尾要集中列出**：作者（年份）《完整题名》，DOI，全部回源核验过——审稿人也要拿得出证据，作者要能反查。正文里引了、末尾没列，这份评审就不严谨。一篇都没引就写明「未引用外部文献」。
